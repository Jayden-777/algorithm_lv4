# algorithm-lv4

주차별(`week1` ~ `week4`)로 정리한 알고리즘 학습용 저장소입니다. 각 주차 디렉터리의 `main.ipynb`에 문제 설명과 풀이 코드가 있습니다.

- **1~2주차**: 우선순위 큐(힙)
- **3~4주차**: 플로이드-워셜(Floyd-Warshall) 알고리즘

## 디렉터리 구조

| 디렉터리 | 주요 내용 |
|-----------|-----------|
| `week1` | 최소 힙: 삽입·추출 연산, 꺼낸 값의 합 |
| `week2` | 카드 묶기(최소 비용 합치기), 계산대 시뮬레이션(이중 힙, 학습용 TODO 포함) |
| `week3` | 방향 그래프의 도달 가능성(간접 경로 포함) |
| `week4` | 최단 순환 경로, 부분 비교 관계로 순위를 알 수 있는 정점 수(관련 KOI 지역본선 유형) |

## 환경

- Python **3.13 이상** (`pyproject.toml` 기준)
- 의존성: **Jupyter** (`jupyter` 패키지)

## 실행 방법

1. 프로젝트 루트에서 의존성을 설치합니다. (예: `uv sync` 또는 사용 중인 도구에 맞는 설치)
2. 원하는 주차로 이동한 뒤 `main.ipynb`를 Jupyter에서 열어 셀을 실행합니다.

## 참고

- 각 주의 `main.py`는 비어 있거나 미사용일 수 있으며, 실습은 노트북을 기준으로 합니다.
